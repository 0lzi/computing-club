# Computing Clup

This Course is designed for KS2 - Year 4-6 (7-11 Year olds). And based loosly around [UK GOV Department of Education Computing Key State 1 and 2](https://assets.publishing.service.gov.uk/media/5a7c576be5274a1b00423213/PRIMARY_national_curriculum_-_Computing.pdf) and aims to prepare students for computing in real world.

All lessons should come with a `.pdf`, `.odf` and `.pptx` for compatibility with different Office suites.

## Topics

1. [Introduction to computers](./01-introduction)
2. [Computers say what](./02-computers-say-what)
3. [Electronics and Microcontrollers](./03-electronics-microcontrollers)
4. [Introduction to Python](./04-introduction-to-python)
5. [Scratch Game](./05-scratch-game)
6. [Encryption](./06-Encryption)
7. [Computer Networks](./07-computer-networks)
8. [Websites from scratch](./08-websites-from-scratch)
